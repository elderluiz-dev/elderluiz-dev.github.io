# Portfólio - Elder Luiz

Portfólio pessoal desenvolvido para a disciplina de Interface Homem-Máquina, com foco em apresentar formação, projetos de estudo, habilidades e formas de contato.

## Tecnologias

- HTML5 semântico
- CSS3
- CSS Grid e Flexbox
- Variáveis CSS
- Media queries para responsividade
- Transições e animações CSS
